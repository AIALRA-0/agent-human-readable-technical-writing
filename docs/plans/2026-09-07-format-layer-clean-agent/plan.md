# 顶层格式层资格计划

## 范围

本阶段只完成格式规则、干净 Agent 触发、自复核、最小补丁和资格证据

本阶段不发布、不安装、不修改远端、不清理分支，也不扩展到文风层

## 固定协议

- 权威规则位于 `references/format-rules.md`
- 规则编号为 `FMT-001` 至 `FMT-110`
- 每个真实案例使用独立任务目录和独立 `CODEX_HOME`
- Agent 只能获得待测 Skill、当前请求和必要素材
- Agent 不得获得历史对话、预期答案、评分标准或其他案例
- 每个正向案例经过触发、初稿、自查、确定性检查、同模型独立复核、精确补丁和全文复验
- 自动局部修复最多两轮
- 自动通过不等于用户接受

## 案例矩阵

- 每轮使用二十个随机来源案例
- 五档输入长度各四个
- 五类受众各四个
- 七个显式触发、九个隐式触发、四个负向不触发
- 正式资格默认运行 Sol、Terra 和 Luna，共六十项
- Astra 只能显式选择，主机不支持时不得计为通过或失败

## 执行顺序

1. 收敛规则、组件配置、Schema、验证器、精确提交器和运行器
2. 运行静态案例、单元测试、Python 编译和差异检查
3. 运行代码混合案例的单模型诊断
4. 冻结 Skill、运行器和请求摘要
5. 启动带资格编号的二十乘三正式矩阵
6. 只修复失败证据能够证明的系统问题，并使用新资格编号重跑
7. 六十项全部通过后生成脱敏资格摘要
8. 交付实机测试入口、命令、结果边界和已知限制

## 完成条件

- 静态案例二十项全部通过并覆盖一百一十条规则
- 所有正向结果在两轮以内闭环通过
- 所有负向控制均不运行写作 Agent
- 所有访问越界计数为零
- 公开报告不含正文、事件、会话标识和用户接受字段
- 用户取得可独立复现的实机测试说明
