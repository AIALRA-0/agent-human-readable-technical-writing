# 补丁规划

## 1. 输入

补丁规划读取结构化 `Finding`、当前文档摘要、节点范围和需要保持的内容；它不能直接修改文件

## 2. 范围选择

按照以下顺序选择能够修复问题的最小范围：

1. 词或符号
2. 短语
3. 单句
4. 信息段落
5. 相邻段落
6. 小节
7. 整体骨架

低一级能够修复时不得升级；最小范围指能够消除当前错误及其直接连带矛盾的最小必要影响范围，不等于修改字符最少；一个判断改变并直接影响多个位置时，每个位置分别选择最低可行范围，再把这些不重叠补丁放入同一事务；未依赖该判断的位置不得进入补丁；整体骨架只用于覆盖关系已经发生结构性错误，并且其他范围无法恢复的情况

## 3. 输出

规划器只输出符合 `contracts/patch.schema.json` 的 `replace_exact` 补丁；补丁必须绑定文档摘要、节点、旧文本、预计出现次数、授权范围、保留项和重新运行的验证器；多个直接依赖位置使用同一文档摘要并作为一批事务提交，任何一个位置失效时整批不写入

## 4. 禁止行为

- 不输出自由文本修改指令
- 不使用正则替换
- 不使用模糊匹配
- 不在补丁中重新生成全文
- 不修改 Finding 没有授权的范围
- 不以最小字符数为由遗漏同一判断的直接依赖位置
