# 一次性问答确认

## 1. 触发条件

只有不同解释会改变事实、范围、结论、来源要求或输出规模时才进入问答确认；普通措辞差异使用任务默认值，不中断写作

## 2. 问答结构

一次问答必须同时说明：

- 决定对象：当前缺少哪项选择
- 可选方案：用户可以选择哪些互斥方案
- 推荐默认：现有信息更支持哪个方案
- 实际影响：每个方案会改变哪些内容、长度、来源或结论边界

## 3. 默认行为

| 用户请求 | 默认任务配置 | 采用原因 |
| --- | --- | --- |
| 翻译这篇论文 | `TRANSLATE + GLOSS` | 用户授权跨语种转换，但没有授权大幅扩展背景 |
| 翻译成我能看懂的中文 | `TRANSLATE + EXPLANATORY` | 能看懂已经授权加入必要背景和机制说明 |
| 只调整排版 | `FORMAT_ONLY + NONE` | 用户没有授权改变语言内容 |

## 4. 阻断状态

用户确认以前不得开始成文；确认结果写回任务契约以后，系统从任务编译继续，不反复询问已经解决的问题
