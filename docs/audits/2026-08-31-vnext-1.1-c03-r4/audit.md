## 4. 规则证据

npm 官方要求品牌名称使用小写，并说明 npm 不是可按首字母展开的名称；该证据决定 `official_form: npm`、`official_case_precedence: true` 和 `acronym_expansion_allowed: false`，来源见 [npm 官方命名规则](https://docs.npmjs.com/policies/logos-and-usage/)

`Package Manager` 是用户确认的括号英文通用类别形式；它说明 npm 所属类别，不声明 npm 的官方英文全称

代码、行内代码、网址、路径和逐字引用继续保持原始字符；原因是这些内容承担机器含义或证据作用，统一改写大小写会破坏可核对性
