# 原文与补充解释分层规则

## 1. 目的

本规则用于防止补充解释被误写成原作者主张；最终正文可以自然表达，但中间层必须保留来源类型和支持关系

## 2. 来源类型

- `SOURCE`：原文直接表达的事实、关系、条件、否定、范围、数值和不确定程度；每项必须指向 `source_span_id`
- `USER_SUPPLIED`：用户在当前任务中提供的事实、读者设定或写作要求；每项必须指向当前任务内的用户输入标识
- `EXTERNAL_BACKGROUND`：帮助理解所需的外部知识；每项必须登记来源，并说明它只承担背景解释
- `INFERENCE`：根据已登记内容得出的解释；每项必须列出支持单元、置信度和不能升级成事实的边界

## 3. 进入正文的条件

任何新增句子至少承担以下一种作用：

- 表达源语义
- 表达用户补充
- 提供有来源的必要背景
- 连接已经登记的必要逻辑
- 解释图片、表格、代码或公式
- 承担不可删除的必要过渡

无法证明作用的句子进入删除候选

## 4. 双重覆盖

改写和翻译分别计算两个指标：

- 源信息覆盖率：承担信息作用的原文单元进入正文的比例；目标为 `100%`
- 补充主张来源覆盖率：正文中的补充主张具有来源或明确推断关系的比例；目标为 `100%`

两个指标独立计算；补充内容不能抵消源信息遗漏

## 5. 自然呈现

正文不需要显示数据库式标签；系统通过就近解释、前置背景或独立补充说明，让读者能够分辨原文主张与帮助理解的解释

## 6. 阻断条件

出现以下任一情况时停止成文：

- 原文位置无法定位
- 同一原文存在会改变结论的多个解释
- 补充事实没有来源
- 推断强度无法确定
- 背景解释可能改变原文立场
